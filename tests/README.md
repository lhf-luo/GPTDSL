# 测试目录

当前测试覆盖补丁筛选与上下文准备的 Python 接口、CLI 及两者的清单衔接。

运行 `uv run pytest -q`。测试创建临时 Git 仓库，覆盖前后版本、实际改动行、文件生命周期、
局部宏和包装函数、缺失/歧义/超限诊断、只读保证、可重复结果与 CLI 导出。
筛选测试另外覆盖历史范围与规模限制、根/合并提交、弱信号、离线待复核、源码证据校验、
逐项失败隔离、模型请求格式与错误处理。模型服务全部模拟，不发送外部请求。
提交清单测试覆盖精确选择、文件顺序、BOM/注释、完整及短 SHA 去重、错误隔离和参数互斥，
并对两个命令共用的清单格式执行回归检查。

无需真实内核、模型或 CodeQL。后续需要外部环境的集成检查应单独组织。
